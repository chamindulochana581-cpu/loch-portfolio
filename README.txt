LOCH — DARK PREMIUM PORTFOLIO WEBSITE
======================================

HOW TO OPEN (WINDOWS 11)
1. Extract the ZIP file.
2. Open the LOCH_Portfolio folder.
3. Double-click index.html to open it in Chrome.
4. No installation, server, or internet connection is needed for core features.
   Fonts load from Google when connected; fallback fonts work offline.

FILES
- index.html  : Sections and website text
- style.css   : Design, responsive layouts and animation
- script.js   : Mobile menu, project filters, scroll animations
- assets/favicon.svg : Browser tab logo

PERSONALIZE BEFORE SHARING
- Change the demo project descriptions to reflect work you've actually built.
- Replace the Fiverr homepage URL in index.html (id="fiverr-link") with your
  own VERIFIED public Fiverr Gig or Profile URL.
- Update any copy to reflect your actual experience and deliverable services.
- Demo projects are clearly labeled as concepts, not real client commissions.

NO frameworks, keys, paid APIs, paid hosting, or build step are required.
Don't upload personal credentials or sensitive customer details to the site.
